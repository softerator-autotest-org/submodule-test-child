# submodule-test-child

A test repository for Softerator. It is the submodule of [submodule-test-parent](https://github.com/softerator-autotest-org/submodule-test-parent), which Softerator clones to check that git works in its sandboxes.

Softerator's production builds depend on both repositories. Do not rename, delete, or make them private.
